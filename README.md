#(Слабо) умный календарь с мультиплеером

##Функции:
### Осноыные
-Сам календарь с визуалом
-Часовые пояса
-Возможность отмечать время, когда свободен
-Возможность запланировать события
-Мультиплеер(Сравнить графики свободного времени для группы участников)

### Возможные:
-Выбор типа календаря(Еврейский, Халяльский)
-Отмеченные праздники
-Настройка интерфейса
